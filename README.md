## Keeping it true

These pages describe what the game actually does: no accounts, ads, analytics, tracking or network use, and saves only on the player's iPhone. The game lives in the private repo `indxneo/nightcoffee`; any change there that adds a network call, analytics, an account, a purchase or data stored off the device updates `privacy.md` here in the same piece of work, along with the App Store's App Privacy answers ("Data Not Collected" today). Keep the effective date current when the policy changes. The contact address is the developer's support email, alishersv.dev@outlook.com (chosen Oct 24); use no other address. This repo is public: never copy private project files into it.
