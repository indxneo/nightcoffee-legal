# Night Coffee: public pages

The public pages for the iPhone game Night Coffee, to be published with GitHub Pages at <https://indxneo.github.io/nightcoffee-legal/> (once Pages is turned on in Settings → Pages; until then, read them here on GitHub):

- [privacy.md](privacy.md): the privacy policy (App Store Connect's Privacy Policy URL), <https://indxneo.github.io/nightcoffee-legal/privacy/>
- [support.md](support.md): the support page (App Store Connect's Support URL), <https://indxneo.github.io/nightcoffee-legal/support/>
- [index.md](index.md): the home page linking both

Questions or problems: [open an issue](https://github.com/indxneo/nightcoffee-legal/issues).

## Keeping it true

These pages describe what the game actually does: no accounts, ads, analytics, tracking or network use, and saves only on the player's iPhone. The game lives in the private repo `indxneo/nightcoffee`; any change there that adds a network call, analytics, an account, a purchase or data stored off the device updates `privacy.md` here in the same piece of work, along with the App Store's App Privacy answers ("Data Not Collected" today). Keep the effective date current when the policy changes. Contact stays on GitHub Issues unless the developer chooses an email address to publish. This repo is public: never copy private project files into it.
